## Changes

- Track the feed card/target that native hover recovery synthetically entered.
- Dispatch paired synthetic `pointerout`/`mouseout`/`pointerleave`/`mouseleave` before nudging a different card or clearing navigation/pointer state.
- Keep synthetic recovery events from rewriting the cached physical pointer coordinates used for card geometry lookup.
- Add a Home fixture regression with a stale full-page preview overlay over two Home cards; the test asserts only the current card remains in the simulated YouTube hover state.
- After failed human QA, broaden native preview video detection to modern inline preview hosts and retry playback recovery across the delayed preview insertion window.
- Treat paused stale frames as unhealthy even when `currentTime` is non-zero; fallback now clears only when the preview is actually unpaused.
- After user clarified the failure is watch -> YouTube logo/sidebar Home, keep nudging the Home card when a paused stale preview is under the pointer instead of treating that stale preview as success.
- Clear pending native-preview playback retries on SPA navigation changes.
- Tighten live smoke so watch-to-Home hover must click YouTube's own Home navigation and show advancing playback, not merely a visible paused preview.
- Add a fixture regression for delayed `yt-inline-player-view-model` preview insertion after watch-to-Home navigation.
- Add a fixture regression for a paused identity-less stale preview overlay that would otherwise block the card hover nudge.
- Keep Home/Search feed hover native-only; no grow/highlight classes are reintroduced.
